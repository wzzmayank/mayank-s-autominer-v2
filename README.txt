Mayank's AutoMiner v2 (Fabric, Minecraft 1.21.11, client-side)

COMMANDS
  /automine <block> [amount]           e.g. /automine diamond_ore 10
  /automine scan <block> | scan off    ESP only
  /automine config <opt> <true|false>  opt: esp, combat, eat, safety, pickup
  /automine status
  /automine stop

FEATURES
  ESP (green markers + red line), tunnel+mine with best tool, fights only mobs that hurt you,
  auto-eat from hotbar, skips blocks next to lava / gravel above / digging into holes,
  stops at low health, collects dropped items, skips stuck blocks, avoids nearly-broken tools,
  pauses when a menu is open, on-screen status line.
